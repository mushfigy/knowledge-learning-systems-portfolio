The reconstructed learner journey follows eight stages from an identified learning need to an informal readiness decision, showing how support, evidence gaps and cross-stage root causes prevent consistent verification of independent-work readiness.

ALT TEXT
A two-row learner journey titled “From Learning Need to Readiness Decision” shows eight stages for a new engineer using specialist simulation software. Stages 1 to 4 cover understanding the requirement, locating learning inputs, building initial orientation and observing standard work. An orthogonal connector continues the sequence to Stages 5 to 8: practising the workflow, resolving gaps, performing the first assignment and receiving a readiness decision. Each stage includes a goal, action, question, required support, evidence produced, an exact failure point and a stakeholder handoff. Five root-cause influence spans show where fragmented learning content, an undefined progression standard, trainer-dependent delivery, readiness without standard evidence and an uncontrolled content lifecycle affect the journey. Two panels compare the current journey end—an informal readiness decision based on inconsistent supporting evidence—with the required capability end of independently completing standard technical work with verifiable readiness. The final diagnosis states that independent-work readiness cannot be verified consistently.
